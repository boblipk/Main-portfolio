University project / C

Hash Table User Registry

I implemented the core functionality of a user registry in C using a fixed-size hash table with separate chaining. In hash_table.c, I created functions to initialize the table, map user IDs to buckets, search for users, register or update records, validate passwords, free allocated memory, and load users from a file.

The project uses C, the standard library, arrays, structs, linked lists, dynamic memory allocation, and file I/O. One challenge was handling hash collisions by linking multiple users within a bucket. I also developed my skills in managing memory and checking for invalid input and file errors across the hash-table operations.

University project / Java

Incident dispatch system

I developed a Java command-line incident dispatch system that allows users to add, view, process, search, and analyze emergency incidents. The application uses a custom linked-list queue to organize incidents, placing high-priority incidents at the front while preserving the order of low-priority incidents. It also tracks unique incident types and compares today's activity with yesterday's data.

The project was built using Java, Java Collections such as HashSet, Scanner for console input, UUID for unique incident IDs, and Instant for timestamps. I independently designed and implemented the incident model, queue logic, priority handling, search features, trend analysis, input validation, and formatted console output.

One of the main challenges was maintaining the correct queue order while ensuring that high-priority incidents were processed first. This project strengthened my skills in Java, object-oriented programming, linked lists, collections, searching and filtering data, input validation, and data structure logic.

Team project / Java

Messaging app project

I worked with a team to build a Java messaging application. Users can register and log in, create chats, send and interact with messages, manage contacts, and save their data between sessions.

I contributed the chat and message features, including chat viewing and deletion, message sending and deletion, and storing messages in a linked list. The project uses Java and its collections, such as LinkedList and ArrayList, along with file I/O for saving and loading app data.

One challenge was keeping chat and message actions organized as features like viewing, editing, and deleting messages came together. Through this work, I developed my skills in object-oriented programming, choosing data structures for application features, and collaborating on a shared project.
